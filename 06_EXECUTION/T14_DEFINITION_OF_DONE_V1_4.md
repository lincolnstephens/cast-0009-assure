## What the gate does not check

- **Whether a broken server would have confirmed the task.** Line 34 sends the confirm request to a real client task and expects it to be refused. If the refusal were broken, that task would be confirmed. The unit tests in `packages/server/test/clientView.test.ts` prove the refusal first, against a test store.
- **A grey tile on real data.** The demo has no grey tile, so line 32 measures grey on a probe tile that it adds and then removes.
